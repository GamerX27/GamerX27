# Hi, I'm X27 👋

Linux user and gamer from Norway. I run a homelab at home, self-host as much as I can and I really like FOSS.
Most of what I make started as something I needed for my own setup, so it's built around how I use my machines.

All my projects are hosted on my own Forgejo server at [git.xlabsx27.com](https://git.xlabsx27.com/X27).

[![Forgejo](https://img.shields.io/badge/Forgejo-X27-orange?style=for-the-badge&logo=forgejo&logoColor=white)](https://git.xlabsx27.com/X27)

## What I'm working on

- [X27-Linux](https://git.xlabsx27.com/X27/X27-Linux): my own Fedora Kinoite 44 images built with BlueBuild. They come with the CachyOS kernel, Brave, Bazaar and a dark KDE setup. There are Base, LTS, Gaming, Desktop and Media PC versions.
- [X27-Linux-Homelab](https://git.xlabsx27.com/X27/X27-Linux-Homelab): a small headless Fedora server image where everything runs in Docker. It has its own auto-update tool with Gotify notifications and a menu for updating containers.
