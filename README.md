# Hi, I'm X27 👋

Linux user and gamer from Norway. I run a homelab at home, self-host as much as I can and I really like FOSS.
Most of what I make here started as something I needed for my own setup, so it's built around how I use my machines.

Most of my stuff lives on Codeberg. GitHub is mainly a mirror, but the Linux images and Docker images are built here since they use GitHub Actions and ghcr.io.

[![Codeberg](https://img.shields.io/badge/Codeberg-X27-blue?style=for-the-badge&logo=codeberg&logoColor=white)](https://codeberg.org/X27)

## What I'm working on

**Linux images**

- [X27-Linux](https://github.com/GamerX27/X27-Linux): my own Fedora Kinoite 44 images built with BlueBuild. CachyOS kernel, Brave, Bazaar and a dark KDE setup. Comes in Base, LTS, Gaming, Desktop and Media PC versions.
- [X27-Linux-Homelab](https://github.com/GamerX27/X27-Linux-Homelab): a small headless Fedora server image where everything runs in Docker. Has its own auto update tool with Gotify notifications and a menu for updating containers.

**Homelab and Docker**

- [Docker-X27-Composes](https://codeberg.org/X27/Docker-X27-Composes): the compose files I use for the services in my homelab.
- [Docker-Images](https://github.com/GamerX27/Docker-Images): container images I build myself, like Dev-Box, unbound and X-Dashboard.

**Tools and scripts**

- [X-Linuxtool](https://codeberg.org/X27/X-Linuxtool): a menu that downloads and runs my Linux setup scripts for desktop, gaming and homelab.
- [X-YT-DLP-Archiver](https://codeberg.org/X27/X-YT-DLP-Archiver): a self-hosted web UI for yt-dlp. Paste a link, pick the quality and it sorts the files into folders for you. Works with Jellyfin too.
- [YTDLP-Easy-Script](https://codeberg.org/X27/YTDLP-Easy-Script): a simpler script for downloading with yt-dlp from the terminal.
- [X27-Fastfetch-Config](https://github.com/GamerX27/X27-Fastfetch-Config): my fastfetch config.

## Stuff I use

Fedora, KDE Plasma, Docker, fish, BlueBuild, GitHub Actions and a lot of bash.
